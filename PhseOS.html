⚠️ 重要说明

PhseOS 是一个伪OS项目，它使用高级语言（Python）模拟低级硬件环境。 例如使用 JSON 文件模拟内存，用配置文件定义寄存器结构等。 这不是一个真正的操作系统（不使用UEFI/BIOS），而是一个用于学习和理解计算机原理的仿真平台。

核心特性

为学习和研究而设计的仿真环境

🧠

可配置内存

默认 1024 字节内存，可通过 build.json 灵活调整内存大小。

⚙️

灵活寄存器

支持 8 个 8 位寄存器，可根据需要自定义寄存器宽度和数量。

🐍

Python 驱动

使用 Python 编写，易于理解和扩展，适合学习硬件模拟原理。

📦

JSON 配置

所有硬件配置通过 JSON 文件管理，无需修改代码即可调整参数。

🐛

调试模式

内置调试模式支持，方便查看和跟踪模拟器的运行状态。

📚

PhseX 库

可扩展的外部库系统，支持 PhseX_library 功能模块。

默认配置

build.json 配置文件参考

配置项 类型 默认值 描述
RAM_file 路径 hardware\RAM\memory.json 内存文件路径
REG_file 路径 hardware\CPU\register.json 寄存器文件路径
memory_size 整数 1024 内存大小（字节）
reg_set.reg_width 整数 8 每个寄存器的位数
reg_set.reg_count 整数 8 寄存器数量
PhseX.debug_mode 布尔 true 是否启用调试模式
